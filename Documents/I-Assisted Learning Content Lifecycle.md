# AI-Assisted Learning Content Lifecycle

**Version:** 1.0 (Draft)

**Purpose**

Defines how AI-generated educational content becomes part of the Learning Workspace learning experience.

---

# 1. Core Principle

## AI Assists, Domains Own

AI does not own educational content.

AI creates:

- suggestions;
- drafts;
- recommendations;
- generated assets.

The Learning Delivery Context owns:

- lessons;
- activities;
- learner experiences.

---

# 2. Content Creation Lifecycle

```
Teacher Input

↓

AI Analysis

↓

AI Suggestions

↓

Teacher Review

↓

Learning Asset Creation

↓

Lesson Published

↓

Learner Experience
```

---

# 3. AI Content Generation Flow

## Step 1 — Teacher Provides Source Material

The teacher may provide:

- video upload;
- video URL;
- document;
- presentation;
- existing lesson.

---

Example:

Teacher uploads:

```
fractions_lesson.mp4
```

---

# Step 2 — AI Content Understanding

AI analyses the source.

AI extracts:

- transcript;
- topics;
- concepts;
- keywords;
- examples;
- learning objectives.

---

Example:

Input:

```
45-minute mathematics video
```

AI output:

```
Topic:

Equivalent Fractions


Key Concepts:

- numerator
- denominator
- equivalent values
```

---

# Step 3 — AI Lesson Draft Generation

AI proposes:

## Lesson Title

Example:

```
Understanding Equivalent Fractions
```

---

## Lesson Description

Example:

```
Students learn how fractions with different
numbers can represent the same value.
```

---

## Learning Objectives

Example:

```
By the end of this lesson, learners can:

- identify equivalent fractions;
- compare fraction values.
```

---

# Step 4 — AI Interactive Content Generation

Using transcript and extracted concepts, AI generates:

- questions;
- activities;
- exercises;
- discussion prompts;
- summaries.

---

Example:

Transcript:

```
A fraction represents part of a whole.
```

AI generates:

Question:

```
What does the denominator represent?
```

---

# Step 5 — Teacher Approval

Teacher can:

- accept;
- edit;
- remove;
- add content.

---

Teacher remains responsible for:

- correctness;
- teaching style;
- educational quality.

---

# Step 6 — Learning Delivery Creation

After approval:

AI output becomes:

```
Learning Delivery Entity

Lesson

+

Activities

+

Resources
```

---

```

Lesson

```

# 5. AI Generated Content States

An AI-created asset has lifecycle:

```
Generated

↓

Under Review

↓

Approved

↓

Published

↓

Archived
```

---

# 6. Versioning

The platform should preserve content history.

Example:

```
Lesson Version 1

Created by AI


Teacher edited


Lesson Version 2

Published
```

---

# 7. Future AI Enhancement

The system can later support:

## AI Lesson Improvement

AI analyses:

- learner performance;
- completion rate;
- common mistakes.

Then suggests:

```
Add more examples after section 3.
```

---

## AI Personalisation

The same lesson can generate different versions:

```
Beginner Version

Advanced Version

Visual Learner Version

Exam Preparation Version
```

---

# 8. Architectural Rule

AI should never directly publish educational content.

The required flow:

```
AI

↓

Teacher

↓

Learning Delivery

↓

Learner
```
